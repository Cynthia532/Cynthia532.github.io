# 精细模型第一版

2026-09-30。灰模已获确认，本轮在同一键鼠交互基础上细化角色、完整房屋和软装。当前模型由 Three.js 几何与材质生成，保留可编辑部件；没有生成 Blender 源文件、GLB 或蒙皮动画。概念图继续作为后续形体、色彩和动作的美术基准。

## 本轮场景

- `StudyHouse` 包含房屋与庭院；`InteriorContents` 在门外也存在且保持可见，由真实墙体和屋顶遮挡。
- `Wall_Entrance` 建有内外两侧、双面拱门、门框、踢脚线；室内门墙有挂画与小搁板。
- 其他三面墙及 `RoofAndCeiling` 形成完整房壳，屋顶包含前后山墙。门外可看到门廊、铺石、花盆和灌木，没有独立空立面。
- 室内采用剖面视角：屋顶隐藏，近镜头一侧墙隐藏，其余墙保留。旋转至房间后方时，入口墙和门的内侧重新显现。门外恢复全部墙体和屋顶。
- 新增奶油色双人沙发、草莓粉靠枕、花形抱枕、圆凳、边桌、灯、办公椅、地毯、画框和多种植物；书架、桌面夹板、衣柜内部也有细节。
- 角色补充脸部、耳朵、发束、帽檐、领口、袖口、挂绳、鞋子；开衫与连帽衫具有独立结构。头部、四肢、帽子与上衣细节保留独立组，支持现有呼吸、眨眼、行走和伸手动作。

## 未来家具交互接口

接口在 `room-app/src/furniture-actions.ts`；场景创建结果的 `world.actions` 持有注册表。家具带有 `furnitureId`、`futureAction` 和 `actionAnchors` 元数据；锚点是真实的 Three.js 节点，使用 `getWorldPosition()` / `getWorldQuaternion()` 取得世界坐标与方向，不能直接把局部坐标当作角色位置。

| 稳定 ID | 动作 | 锚点 / 部件 |
| --- | --- | --- |
| `sofa` | `sit` | `seatLeft`、`seatRight`、`approach`、`stand` |
| `plant-floor` | `water` | `approach`、`water`、`spout`、`growth`、`soil` |
| `plant-window` | `water` | 同上，接近位置放在窗前地面 |
| `plant-bookshelf` | `water` | 同上，接近位置放在书架前地面 |
| `plant-papers` | `water` | 同上，接近位置放在论文书架前地面 |

`bind(id, handler)` 安装回调并返回清理函数，`isEnabled(id)` 检查是否开启，`activate(id)` 调用已绑定动作。未绑定动作返回 `false`。土壤网格没有合批，后续可以改变湿润颜色；植株生长组也独立保留。

接入新动作时还需在输入拾取、距离判断和主状态机中增加对应入口，然后由状态机调用 `activate()`。坐下时暂停探索移动、对齐座位，起身恢复地面位置；浇水时可沿 `spout` / `water` 制作水壶与水流动画。本轮仅预留结构，尚未实现坐下或浇水，也不显示这些动作的按钮或悬停提示。

碰撞体集中在 `src/layout.ts`，并由移动系统和动作注册表共享。新增沙发、边桌、圆凳、椅子和地面植物的阻挡范围，保留中央动线和衣柜展示通道。更改家具尺寸或位置时同步修改对应范围。

## 资源与性能

同材质静态网格合批，重复书籍 / 灌木先合并；门轴、纸张、柜门、家具根节点和动作锚点保持独立。阴影使用 1024 像素贴图，仅在移动、过渡、转镜头或换装时更新；静止场景复用阴影。

本轮浏览器软件渲染抽样：转向入口墙的静止视角约 252 次绘制、123,571 个三角形；不同视角、可见服装及阴影更新帧会变化。此值仍高于原设计的 100 次绘制 / 10 万三角形目标，后续需要继续合批、降低小物件网格密度并在实际桌面 GPU 上测帧率；目前不宣称达到 60 FPS。

构建后的房间 JS 约 613 kB，gzip 约 161 kB。当前没有外部模型下载，图案和画框纹理由代码绘制。原始个人照片不进入网页资源。

本机地址：`http://localhost:4173/room/?lang=zh`。完整操作和构建方法见 [预览说明](../../room-app/README.md)。已接受的灰模源码留在 `greybox-20260930/`，作为结构参考快照；它不是单独可运行的第二份工程。
